# 坦克大战 (Battle City)

经典 90 坦克大战网页复刻版，基于 HTML5 Canvas 和 JavaScript。

## 玩法

- **移动**：WASD 或方向键
- **射击**：空格键或 J 键
- **目标**：消灭所有敌人坦克，保卫基地（鹰）不被摧毁

## 游戏特性

- 5 个精心设计的关卡，循环挑战
- 4 种敌人类型（基础、快速、强力、装甲）
- 5 种道具（火力升级、额外生命、暂停敌人、无敌护盾、全屏轰炸）
- 玩家 3 级火力升级系统
- 本地最高分记录
- 实时光影效果和屏幕震动

## 快速开始

直接在浏览器中打开 `index.html` 即可开始游戏。

## 技术栈

- HTML5 Canvas
- 纯 JavaScript（无框架）
- Web Audio API 音效
